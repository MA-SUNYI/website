This is the same dice mechanism as the random dice roller page, kept separate for the shorter search phrase. The logic is identical: uniform random selection across the faces, with each roll independent of every previous one.

For tabletop players the useful detail is distribution, not fairness. A single d20 gives every value from 1 to 20 an equal 5% chance; 3d6 clusters heavily around 10 and 11 because there are more ways to make those totals. When a game system says 'roll 3d6 for stats', it is deliberately producing a bell curve rather than a flat spread — characters end up average far more often than exceptional.

Practical use is straightforward: set the number and sides, roll, and read the total. For games that need specific handling of natural 1s and 20s, note the individual face values rather than only the sum, because the sum alone hides which die carried the critical.

Frequently Asked Questions

Do the dice roll randomly every time?

Yes. Each roll draws from a uniform distribution across the faces, with no memory of previous results.

What is the average roll on a single d6?

3.5, the midpoint between 1 and 6. Over many rolls the average converges to that value even though it can never be rolled exactly.

Why does 3d6 cluster in the middle?

There are more combinations that total 10 or 11 than any other value, so those results dominate. The more dice, the tighter the bell curve.

Can I roll several different dice types at once?

Roll each set separately and add the totals, or note the results in order if a mixed pool is needed.
