A password generator that shows advertisements is a strange proposition: the page asks you to trust it with a security task while simultaneously monetising your attention. This version keeps the generator to a single screen with no interstitials and no forced waits.

The security property that matters is locality. A generator that runs entirely in the browser never transmits the generated value, which is verifiable by checking that the page still works offline. Any generator requiring a network round-trip to produce a password has an unnecessary exposure, however small.

It is worth saying plainly that the advertising model and the security model here are not in conflict — ads on the page do not affect the randomness of the output. What does matter is what the page does with your input, and the answer here is nothing: no storage, no logging, no transmission.
