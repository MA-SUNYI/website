A square root asks which number, multiplied by itself, gives the value you started with. For perfect squares the answer is exact — √144 is 12, √625 is 25 — and for everything else it is an irrational number whose decimal expansion never ends and never repeats.

There are two ways to find it by hand. The first is approximation: √50 sits between √49 = 7 and √64 = 8, and closer to 7, so around 7.07. The second is Newton's method, which converges fast: start with a guess g, compute (g + n/g)/2, and repeat. Starting at 7 for √50 gives 7.0714 on the first pass, already correct to four digits.

Watch for the domain restriction. Square roots are defined only for non-negative real numbers, and a calculator returning an error for a negative input is behaving correctly — the square root of −9 is 3i, a complex number, not a real one. The related but distinct operation, squaring, has no such limit, which is why the two are easy to confuse in reverse.

Frequently Asked Questions

What is the square root of a number squared?

√(x²) equals the absolute value of x, not x itself. For x = −5, √25 = 5, so the sign is lost — a detail that trips up algebra students regularly.

How do I estimate a square root without a calculator?

Bracket it between two perfect squares and interpolate. √70 sits between 8 (64) and 9 (81), roughly a third of the way along, so about 8.37. The estimate is usually within a percent.

Why does my calculator show an error for a negative input?

Because no real number squares to a negative value. The result exists only in the complex plane.

What is the difference between a square root and a cube root?

A square root undoes squaring (x²); a cube root undoes cubing (x³). Cube roots of negative numbers are defined, since a negative cubed stays negative.
