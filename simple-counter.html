A counter sounds too trivial to need a page, but the plain version is genuinely the most useful: no account, no sync, no settings to configure, just a number you can increment while your hands are busy with something else. Clicking, tapping or pressing a key adds one; the value persists while the page is open.

The friction that makes people seek a simple counter is almost always the register-wall problem — sites that require a login before you can tally anything. That is a strange requirement for counting, and this tool deliberately avoids it. It also avoids cloud sync, which means your counts never leave the browser.

For long counting sessions, keep the tab pinned so an accidental refresh does not reset the total, and note the count somewhere durable before closing. Anyone tallying inventory, attendance, reps or repeated events runs into the same two failure modes: losing the number and miscounting double-taps. The first is a storage problem, the second a UI problem, and neither is solved by adding features.

Frequently Asked Questions

Does the counter save my number if I close the tab?

The count is held in the page's memory while it is open. Closing or refreshing clears it, so write the value down before you leave.

Can I count down instead of up?

Increment counting is the default. For a running total that needs to decrease, subtract as you count and reconcile at the end, or use a two-column tally.

Is there a maximum count?

No practical limit for counting purposes. The displayed value continues past any hand-tally range you would realistically reach.

Why would I need an online counter at all?

Because the device you are holding is already in your hand. For counting repeated physical events — reps, parts, passes — a tap is faster than paper and does not require finding a pen.
